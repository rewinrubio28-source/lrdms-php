# Ordinance Process Workflow

*Gathered from interview — for reference in the LRDMS (Legislative Records & Document Management System) project.*

## 1. Main Document Process Flow

```
Records
  → Office of Mr. Yupangco (approves documents)
  → Agenda (for tackling in session)
  → Records
  → Agenda & Briefing (online)
  → Forwarded to Councilors
  → Tackle Session
  → Forward to Committee
  → 15 days to call for hearing (multiple hearings acceptable)
  → Chairman Committee Report
  → Records
  → 2nd Reading
  → Session
  → 3rd Reading
  → Signed by Mayor
  → Published
```

## 2. Key Terms

| Term | Meaning |
|---|---|
| **Agenda** | Topic/document lined up to be tackled in session |
| **Session** | Actual tackling/discussion of the topic |
| **Executive** | Mayor's order — takes priority, comes first in agenda |
| **Agenda & Briefing** | Fixing/finalizing documents before they proceed |

## 3. Timing & Approval Rules

- **15-day rule:** If an ordinance/document is pending beyond 15 days, it must be re-followed-up — the proponent should be reminded/asked about the status of their submission.
- **24-hour rule:** Once an ordinance is passed or forwarded for processing, it must be agenda'd (scheduled for tackling) within 24 hours.
- **Auto-approval:** All ordinances are automatically approved by default.
  - Rejected **only** if it cannot be justified.
  - The proponent gets **3 chances** to justify the ordinance.
  - Once justified, it's forwarded to the Mayor for approval.
  - If the Mayor doesn't approve it, it goes back to session to fix the issues.

## 4. Document Access Levels

| Level | Description |
|---|---|
| **Approved** | Published to the public |
| **Records** | Held by the Records Department |
| **Private** | Applies to almost all documents even if technically public — confidential documents require a formal request letter to access |

## 5. Revision / Amendment Flow (triggered after 1st reading)

If there are changes needed after the 1st session/reading, the ordinance goes through this revision path before reaching the 3rd reading:

```
Ordinance
  → Committee
  → Revision
  → Agenda
  → Amendments
  → Proponent
  → Tackle in Session
  → 3rd Reading
```

**Note:** The proponent must **accept the amendments** to finalize the changes. If the proponent does **not** accept them, the ordinance still proceeds to the 3rd Reading as-is.

## 6. Final Step (all paths converge here)

```
3rd Reading → Signed by Mayor → Published
```
